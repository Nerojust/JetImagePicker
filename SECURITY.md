# Security Policy

## Supported Versions

Only the latest published release is supported with security fixes.

| Version | Supported |
| ------- | --------- |
| 2.0.x   | ✅        |
| < 2.0   | ❌        |

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, email **nerojust4@gmail.com** with a description of the issue and
steps to reproduce. You should get a response within a few days. If the
issue is confirmed, a fix will be released and credited to you (unless you'd
prefer to stay anonymous).
